# Trabalho de Programação Concorrente

Trabalho prático sobre sincronização de threads, prevenção de deadlock e semáforos em Java.

## Integrantes

Alunos:
1. Afonso Henrique de Christo Muller

## Conteúdo

Este repositório contém implementações práticas de três problemas clássicos em programação concorrente:

1. **Jantar dos Filósofos** - Análise teórica e solução por hierarquia de recursos
2. **Condições de Corrida** - Demonstração e correção usando semáforos
3. **Deadlock** - Reprodução do problema e solução por ordem de aquisição
